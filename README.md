# Origin

Origin is an experimental Laravel 13 starter-kit ecosystem for a Core account authority and isolated connected applications. Each product ecosystem has its own independent Core; connected applications keep product data local and use minimal versioned authorization projections.

**Status:** pre-1.0 and not approved for public or production use.
